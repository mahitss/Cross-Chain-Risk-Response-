## 1. Executive Summary & Verification Mandate

Master Engineering Mission M006.1 remediates critical preflight diagnosis integrity gaps and unconfigured-destination event-loss hazards identified after M006, across **Base Sepolia (84532)**, **Reactive Lasna (5318007)**, and **Unichain Sepolia (1301)**.

Under strict ₹0 budget, zero-deployment, zero-broadcast, and no-private-key constraints, M006.1 delivers five integrated workstreams:
1. **Workstream A (Durable Origin-Event Acceptance & Uniform Gas Floor):** `CrossGuardReactive.sol` replaces silent unconfigured rejection with durable `DispatchStatus.PENDING_DISPATCH` state storage, adds `dispatchPendingCallback(bytes32,uint256)` (`retryCount == 0` preserved), emits `CallbackDispatchDeferred`, `CallbackDispatchSubmitted`, and `PendingCallbackSuperseded`, isolates deferred dispatch from `retryFailedCallback()` (`DispatchNotPending` / `CallbackNotRequested` / `InvalidCallbackType`), and enforces `MIN_CALLBACK_GAS_LIMIT = 100_000` across constructor (including Stage-1 nonzero gas limits), `setDestinationConfig()`, `dispatchPendingCallback()`, and `retryFailedCallback()`.
2. **Workstream B (Strict Recovery-Preflight Correlation & Receipt Verification):** `crossguard_healthcheck.py --recovery-preflight` enforces mandatory `--position-id`, `--expected-nonce`, and `--reactive-tx-hash`, verifies transaction receipts using pure-Python Ethereum Keccak-256 (`0x01` domain separator verified bit-for-bit against `cast keccak`), enforces `CallbackRequest` correlation, unambiguously matches 6-field `getCallbacks(uint256)` records, reconciles all three chains, adds `DISPATCH_REQUIRED` status (`exit code 0`), and keeps `suggested_command = None` (never printing executable `cast send` commands).
3. **Workstream C (Fail-Closed Economic & ABI Diagnostics):** Introduces strict typed decoders (`decode_uint_strict`, `decode_bool_strict`, `decode_address_strict`, `decode_bytes_strict`, `decode_get_latest_callback_strict`), adds read-only `"gas-price"` and `"base-fee"` `CastRpcRunner` subcommands, implements `estimate_callback_fee_wei()` querying `_gasPriceCoeffPer1000()`, `_extraGas()`, `_maxChargeGas()`, and live destination gas fees, separates System Contract debt (`REACT`) vs Callback Proxy debt (`ETH`), and fails closed (`RETRY_UNKNOWN`) on any missing, empty, or malformed economic/ABI field.
4. **Workstream D (Adversarial, Unit, E2E & Stateful Invariant Suite):** Adds 5 unit tests in `CrossGuardReactive.t.sol` (`33` total), `test16_DeferredPendingDispatchCannotBeRetriedUntilSubmitted` plus handler-based `M006RecoveryInvariantTest` (`6` invariants across `256` runs / `128,000` calls, `0` reverts) in `M006Recovery.t.sol`, `testEndToEndDeferredDispatchAndControlledRecovery` in `CrossGuardE2E.t.sol`, and Tests 68–90 (`90` total Python tests) in `test/ops/test_crossguard_healthcheck.py`.
5. **Workstream E (Threat Model, Runbook, Documentation & Verification):** Updates `docs/security/M006-RECOVERY-THREAT-MODEL.md` (29 threat vectors, INV-01..INV-14), `docs/operations/CROSSGUARD-RECOVERY-RUNBOOK.md` (Path A `DISPATCH_REQUIRED` vs Path B `RETRY_ELIGIBLE` SOP), `README.md`, and this report.

## 2. Workstream Delivery Details

### Workstream A: Durable Event Dispatch & Uniform Gas Minimum (`CrossGuardReactive.sol`, `MockOmniSystemContract.sol`)
- **State Machine:**
  - `enum DispatchStatus { NONE, PENDING_DISPATCH, REQUESTED }` added to `CallbackState` (`getLatestCallback(bytes32)` now returns 5-tuple `(uint256 nonce, CallbackType eventType, bytes memory payload, uint8 retryCount, DispatchStatus status)`).
  - When a valid origin event passes all 11 semantic & monotonic nonce checks in `react()`, `latestOriginNonce[positionId]` and `latestCallback[positionId]` (`status = PENDING_DISPATCH`, `retryCount = 0`) are durably stored first.
  - If destination config is active (`destinationCallback != address(0)`, `destinationChainId == 1301`, `callbackGasLimit >= 100_000`), `react()` transitions status to `REQUESTED` and calls `systemContract.requestCallbackV_1_0(...)`. Otherwise, it emits `CallbackDispatchDeferred(positionId, nonce, cType, "DESTINATION_NOT_CONFIGURED")` and returns cleanly without losing the origin transition.
  - Superseding an un-dispatched `PENDING_DISPATCH` entry emits `PendingCallbackSuperseded(positionId, oldNonce, newNonce)`.
- **Path Separation:**
  - `dispatchPendingCallback(bytes32 positionId, uint256 expectedNonce)`: `onlyOwner`; enforces `DispatchStatus.PENDING_DISPATCH` (`DispatchNotPending`), `InvalidCallbackType`, non-mismatching `expectedNonce`, valid destination config (`callbackGasLimit >= 100_000`); transitions atomically to `REQUESTED`, preserves `retryCount == 0`, and emits `CallbackDispatchSubmitted`.
  - `retryFailedCallback(bytes32 positionId, uint256 expectedNonce, bytes32 reasonCode)`: `onlyOwner`; additionally enforces `status == DispatchStatus.REQUESTED` (`CallbackNotRequested`), `InvalidCallbackType`, and `callbackGasLimit >= MIN_CALLBACK_GAS_LIMIT`.
- **Uniform Gas Floor:** `MIN_CALLBACK_GAS_LIMIT = 100_000` enforced in constructor (including nonzero Stage-1 `_gasLimit < 100_000`), `setDestinationConfig()`, `dispatchPendingCallback()`, and `retryFailedCallback()`.
- **Test Mock Enhancement:** Marked `MockOmniSystemContract.requestCallbackV_1_0` as `external virtual override` so `RevertableOmniSystemContract` can inject external system reverts for atomicity tests (`testExternalSystemRequestFailureRevertsAtomicallyAndPreservesState`).

### Workstream B & C: Fail-Closed Preflight & Economics (`crossguard_healthcheck.py`)
- **Mandatory Inputs:** `--position-id` (`bytes32`), `--expected-nonce` (`>= 1`), and `--reactive-tx-hash` (`bytes32`) must all be provided; CLI exits non-zero with `RETRY_UNKNOWN` if missing or malformed.
- **Pure-Python Ethereum Keccak-256 Topic Correlation (`keccak256`, `keccak256_topic`):** Uses standard Keccak-256 (`0x01` domain separator, NOT NIST SHA3-256), verified against `cast keccak` for all monitored signatures:
  - `ReactiveBreachProcessed(bytes32,uint256,uint256,uint256)` = `0xb44a2925d48889fa1efb56042835dcead754facb2fe908899dc1880829fc1bfd`
  - `ReactiveResolvedProcessed(bytes32,uint256,uint256,uint256)` = `0xf6890d193066a899fa616249180570dd4aae30555865af6e1d827af94fe50c53`
  - `CallbackDispatchDeferred(bytes32,uint256,uint8,string)` = `0x6a77b8c5746636838283f7a9cd4986fc89377b9c0693d1a7009fe6769e62f133`
  - `CallbackDispatchSubmitted(bytes32,uint256,uint8)` = `0x0b6a585def0b552d258a510c8794057594a635da501332805ca301d1e0ac75b5`
  - `CallbackRetryRequested(bytes32,uint256,uint8,bytes32)` = `0x7ccb760978bf912c11fd840082babbb783500085a2a871a12e5fd6a9be6fc5eb`
  - `CallbackRequest(uint256,address,address,uint8,bytes)` = `0xef94dbc611c4b95bf4b8ba34b413972180c2faf26fbb480befacedd83e07b133`
- **Strict Decoders & Read-Only Whitelist:** Added `"gas-price"` and `"base-fee"` to `CastRpcRunner.ALLOWED_SUBCOMMANDS`; added `decode_uint_strict`, `decode_bool_strict`, `decode_address_strict`, `decode_bytes_strict`, and `decode_get_latest_callback_strict` requiring exact 5-tuple decode without silent zero coercion.
- **Conservative Fee & Reserve Adequacy (`estimate_callback_fee_wei`):**
  - Formula: `p_base * (_gasPriceCoeffPer1000 / 1000) * (gas_limit + _extraGas)` rounded up, where `p_base = max(gas_price, base_fee) > 0`, multiplied by integer `--safety-multiplier` (`DEFAULT_RESERVE_SAFETY_MULTIPLIER = 2`).
  - Explicitly distinguishes System Contract debt/reserves (`REACT`, Reactive Lasna) vs Callback Proxy debt/reserves (`ETH`, Unichain Sepolia) and marks `guarantees_future_delivery: False` with documented assumptions.
- **Safety Boundary:** `suggested_command = None` in all `run_recovery_preflight()` outputs; preflight never outputs executable `cast send` commands.

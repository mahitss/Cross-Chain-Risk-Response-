## 3. Canonical ABI Rules Enforced

### Verified Authoritative Layout

Confirmed directly against `src/interfaces/ISystemContract.sol`, `test/mocks/MockOmniSystemContract.sol`, and `cast abi-encode "f(uint8,bytes)" 0 $(cast abi-encode "f((uint256,address,uint64,bytes))" "(1301,0x3333...,300000,0x11223344)")`:
- **Event signature:** `CallbackRequest(uint256 indexed chainId, address indexed sender, address indexed recipient, CallbackVersion version, bytes configuration)`
- **Non-indexed outer data (`abi.encode(uint8 version, bytes configuration)`):**
  - Word 0 (`[0:32]`): `version` (`uint8`, upper 31 bytes must be zero, low byte must be `0` = `CallbackVersion.V_1_0`).
  - Word 1 (`[32:64]`): `cfg_offset` (must equal exact canonical offset `64`).
  - Word 2 (`[64:96]`): `cfg_len` (`>= 192`, fitting within available outer data).
  - Outer padded extent: `cfg_padded_len = ((cfg_len + 31) // 32) * 32`; requires `len(raw_bytes) >= 96 + cfg_padded_len`, every outer padding byte `[96 + cfg_len : 96 + cfg_padded_len]` equal to `0x00`, and exact total length `len(raw_bytes) == 96 + cfg_padded_len` (zero trailing bytes).
- **Inner encoded configuration (`cfg_bytes = abi.encode(CallbackConfiguration_V_1_0)`):**
  - Inner word 0 (`[0:32]`): `tuple_offset` wrapper pointer (must equal exact `32`).
  - Inner head (`[32:160]` relative to `cfg_bytes`, `t_start = 32`):
    - `[32:64]`: `chainId` (`uint256`).
    - `[64:96]`: `recipient` (`address`, upper 12 bytes must be zero via `decode_address_strict`).
    - `[96:128]`: `gasLimit` (`uint64`, must be `<= 2^64 - 1`).
    - `[128:160]`: `payload_offset` relative to `t_start` (must equal exact canonical offset `128`).
  - Payload tail (`[160:...]`):
    - `[160:192]`: `payload_len` (`> 0`, `<= len(cfg_bytes) - 192`).
    - Inner padded extent: `payload_padded_len = ((payload_len + 31) // 32) * 32`; requires `192 + payload_padded_len <= len(cfg_bytes)`, every inner padding byte `[192 + payload_len : 192 + payload_padded_len]` equal to `0x00`, and exact length `len(cfg_bytes) == 192 + payload_padded_len` (zero trailing bytes inside `configuration`).

## 5. Callback-Record Decoder Review

Audited `decode_callback_records()` in `script/ops/crossguard_healthcheck.py` (supports formatted tuple strings from `cast call` and raw ABI hex return data for `getCallbacks(uint256)((uint256,address,uint256,uint256,uint256,bytes)[])`):
- **Confirmed Preserved Guarantees:**
  - Enforces exactly 6 fields per tuple (`blockNumber`, `reactiveContract`, `callbackIndex`, `destinationChainId`, `destinationTxHash`, `error`).
  - Validates `reactiveContract` strictly via `validate_evm_address()` (formatted path) and `decode_address_strict()` (raw ABI hex path) without silent zero-padding of truncated addresses.
  - Range-checks every integer (`[0, 2^256 - 1]`) and enforces valid even-length `0x`-prefixed hexadecimal error bytes (`decode_bytes_strict`).
  - Keeps empty array returns (`[]` / `0x` / exact canonical empty array) as `RETRY_PENDING`, never proof of failure or success.
  - Preserves documented schema limitation (`callback_record_correlation` telemetry and `missing_or_unavailable_evidence`): the official 6-field schema omits recipient address and origin nonce.
  - Rejects multiple matching records (`> 1` matching `reactiveContract` + `destinationChainId == 1301`) fail-closed as `RETRY_UNKNOWN`.
- **Uncovered Raw-ABI Boundary Defects Found & Fixed:**
  1. Non-canonical `arr_offset` (`0`) paired with zero-word length could falsely return `[], None` (pending) instead of failing.
  2. Trailing garbage bytes after `arr_len == 0` raw ABI arrays (> 64 bytes) were ignored.
  3. Element offsets (`elem_offset`) were not checked against `arr_len * 32` or contiguous non-overlapping offsets.
  4. `bytes_offset` inside tuple head was not enforced to equal `192` — allowing `bytes_offset = 0` or `128` to alias tuple header fields (`blockNumber`/`destinationTxHash`) as revert `error` bytes.
  5. Raw ABI `error` byte padding, trailing bytes after the array, and non-multiple-of-32 raw hex lengths were unchecked.
  - Fixed all five boundary checks in `decode_callback_records()` and added regression test `test_110_callback_records_raw_abi_boundary_defects`.

## 12. Remaining Limitations

1. **No Live-Network Validation:** Under the strict ₹0 budget and zero-deployment policy, no contracts are deployed to Base Sepolia (`84532`), Reactive Lasna (`5318007`), or Unichain Sepolia (`1301`), and live Reactive Network `SystemContract` / `CallbackProxy` runtime behavior has not been tested against live RPC endpoints.
2. **Canonical Subset Enforcement Assumption:** `decode_callback_request_data_strict()` intentionally rejects valid-but-non-canonical Solidity ABI layouts (e.g., manual hand-crafted payloads with padded gaps or non-32-byte-aligned raw `bytes configuration` overrides) in `requestCallback(CallbackVersion, bytes)`. This assumes production `SystemContract.requestCallbackV_1_0` emits standard compiler `abi.encode(CallbackVersion.V_1_0, abi.encode(config_))`.
3. **6-Field `getCallbacks` Schema Constraint:** Official Reactive `getCallbacks(uint256)` records remain limited to 6 fields without recipient or origin nonce; preflight correlation still depends on unique `CallbackRequest` receipt logs and fails closed (`RETRY_UNKNOWN`) on multi-record ambiguity.
4. **Offline Static Limits on Forwarded Gas & Settlement Cost:** Exact forwarded destination gas after proxy overhead remains statically unverified (`effective_forwarded_gas_exact: None`), and proxy settlement adequacy relies on operator-supplied `--settlement-gas-requirement` when available.
